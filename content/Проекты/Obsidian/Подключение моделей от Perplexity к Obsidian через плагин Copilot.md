# Подключение моделей Perplexity к Obsidian через Copilot

## Введение

Иногда хочется не выходить из Obsidian ради каждого уточнения: вы пишете заметку, рядом лежат черновики и ссылки, а вопрос к модели возникает прямо по ходу работы. Подключение Perplexity API через Copilot как раз закрывает этот сценарий: можно задавать вопросы из среды заметок и получать ответы с опорой на интернет-поиск, не разрывая контекст.

Это особенно полезно, когда Obsidian уже стал рабочим столом для исследований: нужно быстро проверить факт, расширить идею, спросить по текущей заметке или собрать направление для дальнейшего чтения. Perplexity в такой связке выступает внешним LLM-провайдером, а Copilot — интерфейсом внутри vault.

Важно не путать эту настройку с автоматическим «исследователем без контроля». API-ключ, выбор модели и параметры остаются на стороне пользователя, а качество ответа всё равно нужно проверять по источникам.

---

## Часть 1: Получение API ключа Perplexity

### Шаги 1–2: регистрация и вход

Сначала нужен API-ключ: это то, чем Copilot будет подтверждать, что запросы действительно идут от вашего аккаунта Perplexity.

1. Откройте https://www.perplexity.ai/api
2. Нажмите "Sign In" и зарегистрируйтесь через Google, GitHub или Email

### Шаг 3: Получение API ключа

1. Нажмите на профиль (правый верхний угол) → **Settings**
2. Перейдите в **API Keys**
3. Нажмите "Create New Key"
4. Скопируйте ключ (формат: `pplx-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx`)
5. Сохраните в менеджер паролей, чтобы не искать его заново и не хранить в открытом виде

**Важно:** Никогда не делитесь API ключом и не выкладывайте его в интернет. Это не просто строка для настройки, а доступ к вашим API-запросам.

---

## Часть 2: Установка плагина Copilot

Copilot добавляет в Obsidian чатовый слой, через который можно обращаться к выбранной модели прямо из рабочей базы заметок.

1. Откройте Obsidian → **Settings** (шестеренка слева)
2. Найдите **Community Plugins** → **Browse**
3. Поищите **Copilot** и нажмите **Install**
4. После установки нажмите **Enable**
5. В левой боковой панели (ribbon) появится иконка чата

---

## Часть 3: Добавление API ключа в Copilot

Теперь нужно объяснить Copilot, к какому провайдеру обращаться и какую модель использовать. Здесь важна аккуратность: одна лишняя буква в URL или пробел в ключе часто выглядят как «плагин не работает», хотя проблема только в настройке.

1. Откройте **Settings** → найдите **Copilot** в списке плагинов
2. В разделе **Basic Settings** найдите **API Keys** или **Custom Model**
3. Заполните поля:

```
Model Name: sonar
API Key: [вставьте ваш pplx-xxxxx ключ]
Provider: OpenAI Format
Base URL: https://api.perplexity.ai
```

4. Нажмите **Save**
5. Протестируйте: нажмите иконку Copilot и напишите "Hello"

Если ответ пришёл, базовая связка уже работает: Obsidian отправляет запрос через Copilot, а Perplexity возвращает результат через API.

---

## Часть 4: Выбор модели

Модель лучше выбирать не «самую мощную на всякий случай», а под задачу. Для быстрых уточнений в заметках обычно важны скорость и цена, для исследования — глубина ответа и качество поиска.

| Модель                | Скорость | Цена        | Для чего                      |
| --------------------- | -------- | ----------- | ----------------------------- |
| `sonar`               | Быстро   | Дешево      | Быстрые вопросы, поиск        |
| `sonar-pro`           | Средняя  | $3-15 за 1М | Глубокий анализ, исследование |
| `sonar-reasoning`     | Медленно | $1-5        | Сложная логика, математика    |
| `sonar-deep-research` | Медленно | $2-8        | Полные отчёты, литобзоры      |

**Рекомендация:** Начните с `sonar`, чтобы проверить повседневный сценарий без лишней сложности. На `sonar-pro` имеет смысл переходить для задач, где нужен более подробный анализ или исследовательский ответ.

## Часть 5: Оптимальные настройки

> Для улучшения поиска можно настроить [[Эмбеддинги в Obsidian Copilot для индекса заметок|эмбеддинги]].

Настройки ниже — не магические «идеальные значения», а практичная отправная точка. Их удобно поставить сначала, а потом подкрутить под свой стиль: короткие справки, длинные разборы, поиск по свежим источникам или ответы по заметкам.

### Для ежедневного использования

```
Model: sonar
Temperature: 0.6 (вместо текущих 0.1)
Token Limit: 6000
Websearch: ✅ Включен
Reasoning: ❌ Выключен
Vision: ❌ Выключен
```

### Для исследований

```
Model: sonar-pro
Temperature: 0.7
Token Limit: 10000
Websearch: ✅ Включен
Reasoning: ✅ Включен (опционально)
```

**Параметры:**

- **Temperature** (0.1-2.0): 0.1 = однообразно, 0.7 = разнообразно. Увеличьте до 0.6-0.7, если ответы кажутся слишком сухими или однотипными.
- **Token Limit**: максимальная длина ответа. 6000 для коротких, 10000 для полных ответов.
- **Websearch**: позволяет искать актуальную информацию в интернете, что и делает Perplexity особенно полезным рядом с личными заметками.

## Часть 6: Использование в Obsidian

После настройки Copilot становится не отдельным сервисом «где-то в браузере», а помощником рядом с вашими заметками.

1. Нажмите иконку Copilot в левой боковой панели
2. В чате можно:
   - Задавать вопросы: "Объясни квантовую механику"
   - Использовать текущую заметку: "Объясни концепцию из [[My Note]]"
   - Искать информацию: "Новости в области AI в 2025"

3. Все разговоры автоматически сохраняются как заметки в папку "Copilot Conversations"

Такой формат удобен тем, что удачные ответы не теряются в истории браузера: их можно перечитать, разобрать и при необходимости перенести в постоянные заметки.

## Часть 7: О подписке и платежах

### Perplexity Pro подписка ($5/месяц)

Перед активным использованием стоит отдельно посмотреть на платежи. API-запросы — это не просто «чат в Obsidian», а обращения к внешнему провайдеру, поэтому лучше заранее понимать лимиты и модель оплаты.

**Что это:** Дополнительный месячный бюджет для API запросов (это НЕ то же самое, что Perplexity Pro на сайте за $20).

**Что дает:**

- $5 кредитов каждый месяц для API
- ~3500 запросов моделью `sonar` или ~800 запросов `sonar-pro`
- Удобнее чем платить по факту

**Как включить:**

1. https://www.perplexity.ai/api → **Billing** или **Account**
2. Выберите **"API Credits - $5/month"**
3. Подтвердите платеж картой
4. Кредиты будут пополняться автоматически

**Рекомендация:** Если используете Copilot активно (10-20 запросов/день) — $5/месяц достаточно.

Главная идея здесь не в том, чтобы сразу включать подписку, а в предсказуемости: когда Copilot становится частью ежедневной работы, удобнее понимать, сколько запросов вы примерно тратите.

### Без подписки

- Есть начальный бесплатный лимит
- После исчерпания платите по факту через кредитную карту
- Хорошо для нечастого использования

## Часть 8: Решение проблем

Если что-то не заработало с первого раза, чаще всего причина в ключе, Base URL или слишком тяжёлой модели для выбранного сценария. Начинайте проверку с простого: ключ, интернет, URL, затем уже параметры модели.

| Проблема                    | Решение                                                                                                     |
| --------------------------- | ----------------------------------------------------------------------------------------------------------- |
| **"Invalid API Key"**       | Проверьте, что скопировали весь ключ с `pplx-`. Нет пробелов в начале/конце. Создайте новый ключ если надо. |
| **"Connection refused"**    | Проверьте интернет. Base URL должен быть `https://api.perplexity.ai`. Попробуйте отключить VPN.             |
| **Ответы слишком короткие** | Увеличьте Token Limit до 10000, измените Temperature с 0.1 на 0.7                                           |
| **Очень медленно**          | Не используйте `sonar-deep-research`. Уменьшите Token Limit. Выключите Reasoning если не нужен.             |
| **CORS ошибка**             | Переустановите плагин, обновите Obsidian до последней версии.                                               |

## Заключение

После настройки Obsidian становится чуть ближе к настоящей исследовательской среде: заметки остаются главным местом работы, а Perplexity добавляет быстрый доступ к поиску и LLM-ответам прямо внутри этого процесса.

Теперь можете:

- Быстро искать информацию прямо в заметках
- Анализировать и расширять исследования
- Получать ответы на сложные вопросы с источниками
- Сохранять разговоры в vault и возвращаться к ним позже

**Советы:**

- Тестируйте разные модели для разных задач
- Следите за использованием API в личном кабинете Perplexity
- Экспортируйте ценные разговоры в постоянные заметки
- Используйте теги для организации разговоров

Хорошая настройка здесь ценнее, чем «самая сильная» модель: чем точнее Copilot встроен в ваш способ вести заметки, тем меньше он отвлекает и тем чаще действительно помогает.
