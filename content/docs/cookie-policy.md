## 1. Что используется на сайте

Сайт `slavx.ru` использует ограниченный набор технологий браузерного хранения и аналитики:

- `localStorage` для сохранения пользовательских настроек интерфейса;
- технические данные браузера, необходимые для корректной загрузки страниц;
- аналитический скрипт Plausible, если пользователь согласился на аналитические технологии.

На момент публикации этой страницы сайт не использует рекламные или поведенческие cookie для таргетинга.

## 2. Для чего это нужно

Технически необходимые данные используются для:

- сохранения выбранной темы оформления;
- сохранения отдельных состояний интерфейса;
- запоминания решения пользователя по баннеру согласия;
- стабильной работы элементов сайта.

Аналитика используется для:

- подсчета посещаемости страниц;
- понимания, какие разделы сайта востребованы;
- улучшения структуры и содержания сайта.

## 3. Какие данные могут фиксироваться

В зависимости от сценария использования сайта могут фиксироваться:

- посещенные страницы;
- дата и время визита;
- источник перехода;
- технические сведения об устройстве и браузере;
- выбранные пользовательские настройки интерфейса.

## 4. Управление согласием

При первом посещении сайта пользователю показывается уведомление о технологиях хранения данных и аналитике.

Пользователь может:

- принять использование аналитики;
- оставить только технически необходимые механизмы хранения данных.

Если пользователь не принимает аналитику, аналитический скрипт не должен подключаться.

## 5. Как отключить хранение данных

Пользователь может самостоятельно удалить сохраненные данные через настройки браузера, а также ограничить использование cookie и `localStorage` стандартными средствами браузера. При этом отдельные функции интерфейса сайта могут работать менее удобно.
