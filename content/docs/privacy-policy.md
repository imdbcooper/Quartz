## 1. Общие положения

Настоящая политика определяет порядок обработки персональных данных пользователей сайта `slavx.ru` в соответствии с требованиями Федерального закона РФ от 27.07.2006 № 152-ФЗ «О персональных данных».

Политика применяется ко всем данным, которые оператор получает через сайт, формы обратной связи, форму брифа и иные обращения пользователя.

## 3. Какие данные обрабатываются

Оператор может обрабатывать следующие категории данных:

- данные, которые пользователь указывает в формах:
  - имя;
  - компания или название проекта;
  - телефон;
  - email;
  - Telegram-аккаунт;
  - тип услуги;
  - состав требуемых работ;
  - ориентировочный бюджет;
  - желаемые сроки;
  - сведения о наличии ТЗ, макетов, текущего продукта или доступов;
  - описание задачи;
  - желаемое время обратного звонка;
  - отметка о согласии на обработку персональных данных;
- данные, которые автоматически передаются при использовании сайта:
  - IP-адрес;
  - дата и время запроса;
  - сведения о браузере, устройстве и операционной системе;
  - технические данные HTTP-запроса;
  - данные о посещении страниц сайта;
  - сведения, сохраняемые в `localStorage`, если это необходимо для работы интерфейса.

Оператор не запрашивает специальные категории персональных данных и биометрические персональные данные.

## 4. Цели обработки

Персональные данные обрабатываются для следующих целей:

- приема и обработки обращений пользователя;
- организации обратного звонка и обратной связи;
- подготовки ответа, оценки задачи и коммерческого предложения;
- согласования состава работ, сроков и формата сотрудничества;
- ведения переписки по запросу пользователя;
- улучшения работы сайта и анализа его посещаемости;
- обеспечения корректной работы интерфейса сайта.

## 5. Правовые основания

Правовыми основаниями обработки являются:

- согласие субъекта персональных данных, выраженное путем установки соответствующей отметки в форме и отправки заявки;
- необходимость обработки данных для ответа на обращение пользователя и совершения действий по его запросу;
- законные интересы оператора в части обеспечения работоспособности сайта, его безопасности и базовой аналитики.

## 6. Способы обработки и передача данных

Обработка персональных данных может осуществляться с использованием средств автоматизации и без их использования.

Данные из форм сайта передаются на внешний обработчик формы по адресу `https://app.slavx.ru/api/v1/f/12a7dd50d5c0`, который используется оператором для приема заявок.

Также на сайте может использоваться сервис аналитики Plausible для учета посещаемости и событий просмотра страниц.

Данные не используются для автоматизированного принятия решений, порождающих юридические последствия для пользователя.

Оператор не продает персональные данные и не распространяет их без законных оснований.

## 7. Сроки хранения

Персональные данные хранятся не дольше, чем это требуется для целей обработки:

- данные обращений и заявок: до достижения цели обращения либо до отзыва согласия, если более длительный срок не требуется по закону;
- технические журналы и служебные данные: в течение срока, необходимого для обеспечения безопасности и работоспособности сайта;
- данные аналитики: в обезличенном или агрегированном виде в пределах срока, необходимого для анализа посещаемости сайта.

По достижении целей обработки персональные данные подлежат удалению или обезличиванию, если иное не предусмотрено законодательством РФ.

## 8. Cookie, localStorage и аналитика

Сайт использует технически необходимые механизмы хранения данных в браузере, включая `localStorage`, в том числе для:

- сохранения выбранной темы оформления;
- хранения отдельных пользовательских настроек интерфейса;
- запоминания выбора по уведомлению о cookie и аналитике.

При согласии пользователя сайт может подключать аналитический скрипт Plausible для учета посещений страниц.

Подробнее об использовании cookie и локального хранения данных указано на странице [Политика cookie](/docs/cookie-policy).

- потребовать уточнения, блокирования или удаления данных;

Согласие может быть отозвано в любое время путем направления письма на `info@slavx.ru` с темой «Отзыв согласия на обработку персональных данных».

## 11. Защита данных

Оператор принимает разумные организационные и технические меры для защиты персональных данных от неправомерного доступа, изменения, раскрытия, блокирования, копирования и иных неправомерных действий.

## 12. Изменения политики

Оператор вправе обновлять настоящую политику. Актуальная версия всегда размещается на этой странице.
