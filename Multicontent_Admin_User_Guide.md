# Инструкция по работе с Multicontent Admin

## Что это такое

`Multicontent Admin` — локальная админка для редактирования контента:

- главной страницы
- страницы контактов
- категорий мультиконтента для главной
- правил определения источника трафика

Админка работает только локально. В прод она не публикуется.

---

## Что нужно запустить

Открой два терминала в корне проекта.

### 1. Локальный сайт Quartz

```bash
npm run site:dev
```

После запуска сайт будет доступен по адресу:

```text
http://localhost:8080
```

### 2. Локальная админка

```bash
npm run multicontent-admin
```

После запуска админка будет доступна по адресу:

```text
http://localhost:3100
```

---

## Общий порядок работы

1. Запусти `site:dev`
2. Запусти `multicontent-admin`
3. Открой `http://localhost:3100`
4. Измени нужный контент
5. Нажми `Сохранить`
6. Проверь результат в локальном preview
7. Если всё нормально, сделай `commit` и `push`

---

## Как теперь работать с категориями

Отдельной вкладки `Категории` больше нет.

Категория выбирается прямо в шапке админки, в блоке `Категория для редактирования`.

Что это значит:

- выбрал `Основная` — редактируешь обычный `home.json`
- выбрал `telegram`, `google`, `vk` и т.д. — редактируешь соответствующий `home.<slug>.json`
- формы в `Главная` остаются теми же, меняется только активный вариант контента

### Как переключить текущую категорию

1. В шапке найди блок `Категория для редактирования`
2. Нажми на нужную категорию
3. После переключения открой вкладку `Главная`
4. Редактируй Hero / Focus / Services / FAQ / Contact CTA как обычно

### Как создать новую категорию

1. В шапке нажми `Новая категория`
2. В модальном окне укажи:
   - `Slug`
   - `Название`
   - `Создать на основе`
3. Нажми `Создать и переключить`
4. После этого админка сразу переключится на новый вариант

### Как удалить категорию

1. Переключись на нужную категорию в шапке
2. Нажми `Удалить текущую`
3. Подтверди действие

Удаление не сработает, если:

- категория используется в rules
- категория выбрана как `defaultCategory`

### Правила для `slug`

Допустимы только:

- маленькие латинские буквы
- цифры
- дефис

Примеры:

- `instagram`
- `vk-retarget`
- `partner-1`

Нельзя:

- `Instagram Ads`
- `реклама`
- `tg source`

## Вкладки админки

## 1. Главная

Во вкладке `Главная` редактируется текущая выбранная категория.

Если в шапке выбрана `Основная`, сохраняется:

```text
quartz/static/data/home.json
```

Если выбрана рекламная категория, сохраняется:

```text
quartz/static/data/home.<slug>.json
```

Можно менять:

- Hero
- Focus
- Services
- FAQ
- Contact CTA

Редактор внутри вкладки разбит на субвкладки по блокам, чтобы не работать с одной длинной формой.

### Что нового в редакторе

- для цветовых вариантов карточек и сервисов есть визуальная палитра
- для Material-иконок есть picker с поиском и предпросмотром
- выбор иконки делается не по названию вслепую, а из визуального списка

### Что делать

1. Открой вкладку `Главная`
2. Выбери нужную субвкладку: `Hero`, `Focus`, `Services`, `FAQ` или `Contact CTA`
3. Измени нужные поля
4. Нажми `Сохранить`
5. Нажми `Открыть preview`, чтобы проверить текущую категорию

---

## 2. Контакты

Во вкладке `Контакты` редактируется:

```text
quartz/static/data/contacts.json
```

Можно менять:

- Hero
- быстрые контакты
- workflow
- formats
- FAQ
- CTA

Редактор внутри вкладки тоже разбит на субвкладки по секциям страницы.

### Что делать

1. Открой вкладку `Контакты`
2. Выбери нужную субвкладку: `Hero`, `Быстрые контакты`, `Workflow`, `Formats`, `FAQ` или `CTA`
3. Измени нужные поля
4. Нажми `Сохранить`
5. Нажми `Открыть страницу`, чтобы проверить страницу контактов

---

### Палитра и выбор иконок

Для полей `Цвет` в карточках и сервисах доступны визуальные варианты:

- `Blue`
- `Purple`
- `Orange`
- `Green`

Для Material-иконок в админке есть picker:

1. нажми на поле `Иконка`
2. откроется текущая иконка и список доступных значков
3. при необходимости введи текст в поиск
4. кликни по нужной иконке

Picker используется там, где на сайте рендерятся Material Symbols:

- карточки `Focus`
- иконки результата в `Focus`
- иконки в `Services`
- шаги `Workflow`

Для быстрых контактов в `contacts.json` выбор ограничен безопасными вариантами:

- `send`
- `mail`
- `call`

### Как удалить категорию

1. Выбери категорию
2. Нажми `Удалить категорию`
3. Подтверди действие

Удаление не сработает, если:

- категория используется в rules
- категория выбрана как `defaultCategory`

---

## 3. Правила

Во вкладке `Правила` редактируется:

```text
quartz/static/data/multicontent-rules.json
```

Там настраивается, какой трафик попадает в какую категорию.

### Пример логики

- `utm_source=telegram` → `telegram`
- `referrer содержит google.` → `google`
- `referrer содержит vk.com` → `vk`

### Что можно делать

- менять `defaultCategory`
- добавлять новое правило
- менять `priority`
- менять `type`
- менять `param`
- менять `match`
- выбирать категорию назначения

### Как добавить правило

1. Открой вкладку `Правила`
2. Нажми `Добавить правило`
3. Заполни поля:
   - `Priority`
   - `Type`
   - `UTM param`
   - `Match`
   - `Category`
4. Нажми `Сохранить правила`

### Что означают поля

#### `Priority`

Чем меньше число, тем раньше правило проверяется.

#### `Type`

Поддерживаются:

- `utm`
- `referrer`

#### `UTM param`

Обычно:

```text
utm_source
```

#### `Match`

Для `utm`:

```text
telegram
```

Для `referrer`:

```text
google\.
vk\.com
t\.me|telegram
```

#### `Category`

Категория, контент которой нужно показать.

## Как работает preview

Preview нужен для проверки конкретной категории вручную.

Пример:

```text
http://localhost:8080/?_mc_preview=telegram
```

Preview:

- принудительно показывает выбранную категорию
- не должен менять сохранённый first touch
- нужен только для проверки

---

## Какие файлы реально меняются

Админка меняет только файлы в:

```text
quartz/static/data/
```

Основные:

- `home.json`
- `contacts.json`
- `home.<slug>.json`
- `multicontent-rules.json`
- `multicontent-meta.json`

После любых изменений:

## Полезные сценарии

## Добавить новый рекламный источник

1. Создай категорию, например `instagram`
2. В шапке переключись на неё
3. Настрой контент категории во вкладке `Главная`
4. Перейди в `Правила`
5. Добавь правило, например:
   - `type = utm`
   - `param = utm_source`
   - `match = instagram`
   - `category = instagram`
6. Сохрани правила
7. Проверь:

```text
http://localhost:8080/?_mc_preview=instagram
```

## Изменить только тексты для Telegram-трафика

1. В шапке выбери `telegram`
2. Открой `Главная`
3. Измени Hero / Focus / CTA
4. Сохрани
5. Проверь:

```text
http://localhost:8080/?_mc_preview=telegram
```

## Изменить дефолтный контент для всех

1. Открой `Главная`
2. Измени `home.json`
3. Сохрани
4. Проверь обычную главную:

```text
http://localhost:8080/
```

---

## Ограничения

- Админка локальная, не продовая
- Контакты редактируются, но не маршрутизируются по источнику трафика
- Если категория используется в rules, удалить её нельзя
- `default` удалять нельзя

---

## Если что-то не работает

Проверь по порядку:

1. Запущен ли `npm run site:dev`
2. Запущен ли `npm run multicontent-admin`
3. Открывается ли `http://localhost:3100`
4. Открывается ли `http://localhost:8080`
5. Есть ли ошибки в терминале админки
6. Не сломан ли JSON после ручных изменений

Если нужно техническое описание системы, смотри:
