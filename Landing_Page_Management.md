# 🛠 Управление Главной Страницей (Landing Page)

Вся логика главной страницы была успешно переведена на модульную компонентную архитектуру (Preact), что избавляет вас от необходимости вручную редактировать сложный HTML код в `index.md`.

## 📁 Где лежат компоненты?

Все переиспользуемые блоки хранятся в папке:
`quartz/components/`

- **LandingHero.tsx** — Верхний блок («Автоматизирую продажи...»)
- **FocusGrid.tsx** — Секция «Какие задачи решаю» (карточки с иконками)
- **ServicesGrid.tsx** — Секция «Что делаю» (переворачивающиеся плитки)
- **WorksSlider.tsx** — Секция «Кейсы» (Слайдер проекта OKB)
- **FaqSection.tsx** — Секция «Частые вопросы»
- **ContactCta.tsx** — Блок призыва к обсуждению задачи

## 📝 Как редактировать тексты и данные?

Управление контентом полностью отделено от верстки компонентов. Чтобы заменить тексты, иконки или ссылки, вам **не нужно менять код TypeScript**.

Все текстовые данные вытянуты в удобный JSON-файл:
👉 `quartz/static/data/home.json`

Внутри вы найдете ключи для каждого блока (например `hero`, `focus`, `services`, `faq`, `contact`). Любые изменения в этом файле автоматически отобразятся на главной странице после сборки сайта (команда `npm run dev` или `npm run build`).

## ⚙️ Как работает сборка (quartz.layout.ts)?

Порядок отображения блоков на странице настраивается в файле `quartz.layout.ts` внутри массива переменной `defaultContentPageLayout`.

Если вам когда-нибудь понадобится **поменять секции местами** (например, поставить FAQ выше Services), вам нужно просто поменять их порядок внутри массива `components: [...]` в вызове `Component.LandingContainer()` для `"home"`.

---

**Примечание:** Сам файл содержимого страницы `content/index.md` теперь остается техническим: он хранит только Frontmatter (метаданные для SEO) и подключение скрипта анимаций (`home.js`). Весь визуальный контент генерируется компонентами из `quartz.layout.ts`.

## Локальная админка мультиконтента

Для редактирования JSON-контента главной страницы, страницы контактов, категорий трафика и правил маршрутизации теперь есть локальная админка.

- Запуск сайта в watch-режиме: `npm run site:dev`
- Запуск админки: `npm run multicontent-admin`
- Админка открывается локально на `http://localhost:3100`

Админка редактирует только файлы в `quartz/static/data/`:

- `home.json`
- `contacts.json`
- `home.<category>.json`
- `multicontent-rules.json`
- `multicontent-meta.json`

Продовый сайт не публикует эту админку. Workflow остаётся обычным: изменить локально → проверить → commit/push.
